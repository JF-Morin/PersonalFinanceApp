# Observations

This is a file with the observations of the app after the 2nd compilation

## UI
- Controls/items should have the Material Design from Google: see this website https://m3.material.io/
- The Material Design should be generated by claude-code for this app, not imported from the internet.
- Make sure that controls have a good contrast: for example, the dark theme has light foreground on white background => difficult to see
- Textbox/inputs should have a dark background with a white foreground when in dark mode (reverse in light mode)
    - Same for dropdowns
- All textboxes/text input should be a rectanble with rounded corners
- Rework the login / first user creation to apply the textbox/input design and more polished design
